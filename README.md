# Apex Distribution Website

A free, static business website for Apex Distribution.

## Included
- Responsive mobile/desktop design
- WhatsApp enquiry form
- Click-to-call buttons
- Email and address
- Sections for About, Services, Why Apex and Contact
- No paid hosting required

## Put it live for free
### GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new public repository, e.g. `apex-distribution`.
3. Upload `index.html` and `style.css`.
4. Open Settings → Pages.
5. Under Build and deployment, choose Deploy from branch → `main` → `/root`.
6. Save. GitHub will provide a live `github.io` address.

### Custom domain later
You can buy a domain such as `apexdistribution.in` later and connect it to the free GitHub Pages hosting.
